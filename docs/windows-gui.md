# Windows 蓝图生成器

双击运行 [JiangCityBlueprint-capsule-report.exe](../dist/JiangCityBlueprint-capsule-report.exe)。程序可离线工作。适用 Windows x64 和 Steam 格式 `117` 的单个 `save_…` 备份，配方、建材和设备参数取自 Steam Build `25121460`。

旧版若提示「存档记录数量无效，偏移 215006」，可关闭旧窗口，运行当前链接中的版本，并重新选取同一份备份。旧读取器曾误判大地图建筑的缺省建材清单。 [修复和验证记录](research.md)

## 生成一份蓝图

1. 先把游戏存档复制到游戏安装目录以外，在 GUI 选择该备份。程序只读提取已学科技、已修复节点、已解锁配方和工坊建筑，可在「存档解锁」和「Wiki 产物预设」页签查看。
2. 在「Wiki 产物预设」查看 77 个目标及对应的解锁途径，双击选择目标。指定末端机型或使用自动选择，再填写末端台数。产速留空时按末端额定满产。宽、高、电网余量可分别留空，空白项不设上限。填写时按工坊实际可用值输入。
3. 带级留空时使用本次读取的存档解锁等级。输入 `1,2` 等列表会覆盖默认的允许等级，含有未解锁等级时会提示。原木、石头等基础原料自动纳入外供。如需直接输入半成品，可在「指定外供物料」每行填写一种物料名。可直接保存带有选填空白项的配置，配置文件独立于存档。
4. 选择自动比较、只搜共用上游或只搜独立供料。「少胶囊优先」依次比较建筑数、建材、走线和占地，「建材优先」把建材放在首位。还可选占地优先、共用原料优先、省电优先或自定义顺序。报告并列显示占地、设备、建造胶囊、物流与电线格数、总建材、功耗和产速。
5. 点击窗口右上角「求解并生成 HTML」。成功后可在 GUI 预览格位和物流，点击「打开完整 HTML」查看自包含的交付页。页首直接显示「所需建造胶囊」。页面还包含方案比较、建材清单、外供原料需求、各口日配额、理论产量、摆放图、电网和导入 TXT 下载。目录同时包含独立 TXT、SVG 和格位 JSON。移动 HTML 文件后仍可离线查看和下载。

以下是一个可载入的配置。`plot` 两个位置分别表示宽和高，单独使用 `null` 可放开对应方向。两项都不限时可以省略 `plot`。额定满产、不设电力上限和使用存档带级时，可以分别省略 `rate`、`power_limit_kw`、`belt_levels`。

```json
{
  "target": "绿色晶能",
  "machines": 2,
  "plot": [42, 30],
  "power_limit_kw": 200,
  "belt_levels": [1, 2],
  "modes": ["shared", "separate"],
  "objective": ["power", "area", "materials"]
}
```

可用 `external` 列表指定外供物料。载入含 `manual_daily` 的旧配置时，程序沿用其中的物料名，按新布局重算所需数量。重新保存后使用 `external`。

## 求解条件

- 首先检查 T3 第 5 节点、配方、设备、各级带及分合流的解锁状态。自动机型按占地、额定电力和生产周期选择。物流等级受存档与用户所选范围共同限制。初次搜索无解时，可尝试跳过较低带级。
- 背包和网络仓库为空时也可生成蓝图。按 HTML 中计算的建材和胶囊数量在游戏里备料。
- 布局按外部持续补货计算。HTML 列出每口 16 分钟的用量及逐口取整的总备货量，单口日用量超过单箱容量时可分批补货。
- 以空线仿真末 4 分钟达到目标产速作为导出条件之一。物理成品接出带在蓝图边界向右出货，需在外部接入可清空的收货或转运设施。电力按额定负载核对，按图从边界接入电网。游戏内实际地块碰撞、外部接入和持续生产需要验收。

## 数据和支持范围

产品列表覆盖 Wiki 配方页的 77 项。手工专用配方照常展示，生成受自动设备、已知端口和模型能力限制。当前支持单产物固体物流、八类自动设备、五级地面带与已解锁的地下带。暂不搜索水管、超频、跨区物流、异形地块或现有设施改造。最优性限于求解器搜索的布局及配方候选。当前参数以及制成蓝图使用的 Steam 格式都以本机安装版为准。 [Wiki 配方](https://wiki.biligame.com/jiangcity/产物配方) · [建模与配置参数](solver.md) · [数据验证](research.md)

## 从源码运行与重新打包

使用 Windows x64 上含 Tk 的 Python 3.10 及以上版本。在项目根目录运行以下命令。

```powershell
python -m pip install -r requirements.txt
python -m solver.gui
python -m unittest discover -s tests -v
```

重新打包时安装 PyInstaller，再执行打包脚本。脚本生成 `dist/JiangCityBlueprint.exe`。

```powershell
python -m pip install pyinstaller
./tools/build_gui.ps1
```
