# Steam 工坊设施的逻辑格与碰撞范围

适用于《江城创业记》Steam Build `25121460`。游戏一格为 **16 × 16 像素**。逻辑格用于布置工序及表达进出料端口，像素碰撞范围用于核对建筑能否并排放置。贴图另有自己的尺寸，摆放图用浅色虚线标出机台和进货箱的碰撞范围。 [设备几何](../solver/geometry.py) · [报告实现](../solver/report.py)

「定位格偏移」从逻辑格矩形的左上角计量，单位为格。「碰撞范围」以定位格左上角为原点，按左、上、右、下给出像素坐标。向右和向下为正。用定位格坐标乘以 16 得到像素原点，再加范围偏移即可得到绝对像素坐标。

## 查证与交付

- 用安装版 `BMachine`、`BInBox` 的四向 `setXY`、`rotate` 及 `getRect` 核对参数。`BBase.computeXY` 和 `computeRect` 从贴图尺寸推导碰撞边界。`BConveyorBelt`、`BHideBelt`、`BSplit` 和 `BMerge` 分别提供物流设施的碰撞矩形。 [参数实现](../solver/geometry.py) · [Steam 逻辑端口表](../solver/workshop.py)
- `BBase.isBuild` 以 `IRect.intersects` 比较碰撞，边界接触也要避开。`LFactory.updateBlue` 预览会逐个检查当前地图中的设施，再批量放置。求解和导出额外核对同一蓝图内部的设施碰撞，并按实际外接范围核对地块大小。 [碰撞校验](../solver/collision.py)
- 格位 JSON 的 `collision_rect_px` 给出四条边的绝对像素坐标，顺序为左、上、右、下。`collision_size_px` 给出碰撞宽与高。HTML 仅列出当前方向实际使用的设施，切换方向时随同摆放图、接口和导入文本更新。 [报告实现](../solver/report.py)
