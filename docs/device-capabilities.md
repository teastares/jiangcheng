# 工坊设备与自动规划

适用 Windows 版《江城创业记》Steam Build `25121460`，存档格式 `117`。安装表包含 232 项建筑。本程序在「存档解锁」列出当前存档可建的建筑，选择建筑可查用途、关联科技和自动规划状态。程序接口 `Workshop.device_capabilities()` 可查全部 232 项，也提供每项的存档解锁标记、安装版功率及建材。科技关联来自安装科技表。最终可建资格按存档的建筑 ID 判定，节点、任务或初始能力解锁的建筑可能没有直接关联科技。 [安装数据](../solver/steam_database.json) · [设备目录](../solver/device_catalog.py)

大型进货箱由科技 `271`「大规模货物处理」关联解锁。定位格到两个外部接带位置的偏移如下。两个出口分别与各自下游握手，从箱里最后一个非空堆栈取货，可同时供同种物料给两路。解锁后，共用上游模式尝试在合适的近邻位置以一个双口箱替换两个同物料进货箱或小箱加两出分流器，保留各支路流量并检查碰撞、下游输送和达产。报告按一箱合计日配额、胶囊和建材。双口箱和小箱按同一组目标比较。独立供料模式中各模块拥有自己的进货箱。 [双口箱候选](../solver/large_inlet.py)

智能分流器由科技 `220`「智能分拣物流」关联解锁。普通与智能分流器使用同一物理端口和旋转规则。安装版会为智能分流器额外读取三个过滤配置和「允许任意未设置过滤的物料」标记。生成的同物料分流设置该标记并清空三个过滤槽。启用过滤分流需要把同一条带上各物料的运量、进入顺序、过滤后出口拥堵和配方供给一起建模。 [导入文本编码](../solver/blueprint.py) · [开发者创建的工坊建筑 Wiki](https://wiki.biligame.com/jiangcity/工坊建筑)

安装版依据为 `Setting/build.csv`、`Setting/tech.csv` 的建筑和科技数据，以及本机加载的 `BList.MakeBuild`、`BInBox.rotate`、`GBuildInBox.update`、`GBuildSplit`、`GBuildOverflow` 和相应设备的数据类。公开表的部分表述与安装版不同，例如木箱和储物箱的格数、销售接货开始时间、迷你卫星功率，规划及目录采用目标安装版。合成存档验证四台石材机以一级带达产 80 件/分钟，采用一个双口进货箱，日配额合计 1280 件。智能分流的型号、建材和三路空过滤配置也已离线核对。游戏内导入及连续运行尚未实测。 [工坊建筑 Wiki](https://wiki.biligame.com/jiangcity/工坊建筑) · [实际占位与四向设备核对](device-footprints.md)
