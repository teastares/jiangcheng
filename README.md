# 江城创业记蓝图设计

根据指定《江城创业记》存档的科技、配方和工坊条件，为目标物品设计可建造、可供料、可运行的产线。

## 当前状态

Windows 蓝图生成器从 Steam 存档备份只读提取科技、节点、配方和建筑的解锁状态，按已解锁设备、物流吞吐和选填的电力与净空上限搜索布局。离线 HTML 汇总建材、建造胶囊和各进货口日配额。工作区还保留命令行求解器、算例，以及既有单置换机和双置换机绿瓶蓝图。

[下载最新版 Windows x64 蓝图生成器](dist/JiangCityBlueprint-capsule-report.exe)

## 开始一次设计

提供目标物品，以及一份指定存档的备份，或对应的天机庙节点、已研习科技和 `F11 → 配方` 截图。平台、游戏版本、目标产量、可用地块和允许外供的材料会影响布局。有可用地块截图时，可以按实际障碍、入口和现有线路排布。

产线方案包含建筑和配方、输入输出流量、摆放与朝向、物流与能源接法，以及开工所需的前置条件。交付导入文本时依据同平台、同版本的游戏读写逻辑或分享样本核对格式，并通过游戏内测试记录实际导入和运行结果。 [蓝图设计流程](docs/blueprint-design.md#设计流程)
