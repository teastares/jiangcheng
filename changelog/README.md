## 2026-11-22｜支持设备换向与四向地下重布

- **原因与变更**　将机台换向、换边进货及各向地下带纳入布局候选。统一端口几何、静态核验、仿真、摆放图和导入文本，按胶囊或建材优先级重布与压紧。当时的打包文件为 `JiangCityBlueprint-rotation-opt.exe`。

## 2026-11-22｜压短产线走线并扩展布局搜索

- **原因与变更**　旧自动双绿瓶的列位和行高目标导致走线过长。加入局部直连、多源多汇、工位就近、三路分合流、行位跨度目标与局部压紧。仿真保留多种加工与进货组合，HTML 列出两种供料排法的完整比较指标。当时的打包文件为 `JiangCityBlueprint-layout-opt.exe`。
- **范围与验证**　用同一模型复算旧手工图，验证 16 项自动测试以及七个案例的十三种可行排法。用 Windows 界面生成 41 × 20、200 kW 的共用双绿瓶，核对 HTML、SVG、TXT、JSON 及 EXE。游戏内运行待实测。 [双绿瓶对照与交付](../blueprints/optimized/README.md) · [研究记录](../docs/research.md)

## 2026-11-22｜Windows 求解与导出解除库存限制

- **原因与变更**　建材和建造胶囊不足曾拦截蓝图生成。新版只从存档提取解锁进度，机型选择与布局求解按解锁状态和设计参数执行。HTML 按布局列出所需胶囊、建材及各口日配额。当时的打包文件为 `JiangCityBlueprint-unlock-only.exe`。
- **范围与验证**　10 项自动测试通过，覆盖空库存导出、节点和配方等解锁条件。用空库存合成备份验证 Windows GUI 的双绿瓶蓝图导出，并检查 EXE 启动与包内求解。 [研究记录](../docs/research.md)

## 2026-11-22｜Windows 生成器按外部持续补货设计

- **原因与变更**　旧版在原木无剩余配送额度时中止。新版自动引入基础原料，允许按名称指定外供半成品，并在 HTML 中列出日配额及存档参考数据。旧配置可直接载入。当时的打包文件为 `JiangCityBlueprint-supply-fix.exe`。
- **范围与验证**　Windows 生成器移除每日配送额度和每日一次装箱限制，继续校验建造库存、科技与物流吞吐。10 项自动测试通过。用合成 Steam 117 数据验证零额度求解与 HTML 导出、双绿瓶布局与仿真，以及 EXE 启动和包内配平。 [研究记录](../docs/research.md)
